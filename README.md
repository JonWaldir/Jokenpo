Progam treinando a classe e membro estatico
]
1 - Faça um programa para ler a cotação do dólar, e depois um valor em dólares a ser comprado por 
uma pessoa em reais. Informar quantos reais a pessoa vai pagar pelos dólares, considerando ainda 
que a pessoa terá que pagar 6% de IOF sobre o valor em dólar. Criar uma classe CurrencyConverter
para ser responsável pelos cálculos
2-Faça um programa para ler o preço por litro do combustível e a distância total de uma viagem em quilômetros. O programa deve informar o valor total em reais que a pessoa vai gastar, considerando que o veículo faz uma média fixa de 12.5 km por litro e que há uma taxa estática de 5% para cobrir desgaste e manutenção do veículo.

Criar uma classe FuelCalculator para ser responsável pelos cálculos contendo:

Uma constante estática para a taxa de manutenção (5%).

Uma constante estática para o consumo médio (12.5 km/l).

Um método estático que recebe o preço do combustível e a distância, retornando o valor total final.
